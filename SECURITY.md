# Security

Please report a vulnerability privately through GitHub: on this repository's
**Security and quality** tab, choose **Report a vulnerability**
(<https://github.com/FeitianTech/postquantum-webauthn-platform/security/advisories/new>).
Please do not disclose it publicly before the maintainers have answered.

In scope: the site at <https://webauthndev.com> and the code in this repository. Only
the latest commit on `main` is supported; it is what the site runs.

A useful report names what is affected (a URL, an API route or a file), gives the steps
or requests that show the problem and what an attacker gains, and says which browser
and authenticator were used when that matters.

Test only with credentials, uploads and accounts of your own, never with another
visitor's data, and do nothing that degrades the live site for others (no load,
denial-of-service or high-volume automated testing). Run anything heavier against a
local copy, started as the README's [Run it locally](README.md#run-it-locally) describes.
