    Authenticators

      A web page cannot ask which authenticator transports a browser supports. USB, NFC and Bluetooth security keys are handled by the browser and the operating system and cannot be detected here; the only way to know is to try one.

      Post-quantum

      The browser passes the algorithms a site offers on to the authenticator, ML-DSA included (COSE -48 ML-DSA-44, -49 ML-DSA-65, -50 ML-DSA-87). Whether a credential uses ML-DSA depends on the authenticator, and only a registration can show it: offer ML-DSA in the Advanced Authentication tab and read the new credential's algorithm.
