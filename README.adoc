This project provides an end-to-end platform for exploring WebAuthn user flows secured by post-quantum cryptography. The hosted demo and local setup instructions help you register authenticators, run authentication process, and compare PQC signature suites in a realistic WebAuthn environment. Decoder is integrated for decoding attestation objects, WebAuthn type CBOR responses, authenticator metadata, etc. A FIDO MDS explorer is also built for direct retrieval of authenticator metadata information, and conducting root certificate verification. 
 
## Local Setup

**Scope**
- Uses the same repo `Dockerfile` as deployment.
- Includes the app, the local `fido2/` library copy, prebuilt `liboqs`, and PQC support used in production images.
- Supports the ML-DSA 44/65/87 PQC algorithms bundled by the current container build.

> **Note for Developers:**  
> The recommended local workflow is Docker-based so local development matches deployment as closely as possible. The steps below replace the older manual `venv`/`mkcert` setup path.


## Supported Platforms

- Windows 10/11 (64-bit)  
- macOS (Intel or Apple Silicon)  

A modern browser with WebAuthn support is required:
- Edge, Chrome, Safari, Firefox


## 1. Prerequisites

- **Git**: https://git-scm.com/
- **Docker Desktop / Docker Engine** with `docker build` and `docker run` available locally


## 2. Clone the Repository

```bash
git clone https://github.com/FeitianTech/postquantum-webauthn-platform.git
cd postquantum-webauthn-platform
```


## 3. Build the Local Image

```bash
docker build -t pqc-webauthn-local .
```

This uses the same `Dockerfile` that is used for deployment targets.

## 4. Run the Container

```bash
docker run --rm -p 8000:8000 --name pqc-webauthn-local pqc-webauthn-local
```

Open the platform at `http://localhost:8000`.

Because localhost is treated as a secure context by modern browsers, this local Docker workflow does not require the older `mkcert` certificate setup.

## 5. Optional: Persist the Flask Session Secret

The container creates a Flask session secret on first launch. To keep the same secret across restarts, mount a local directory to the container instance path:

```bash
mkdir -p instance
docker run --rm \
  -p 8000:8000 \
  --name pqc-webauthn-local \
  -v "$(pwd)/instance:/app/instance" \
  pqc-webauthn-local
```

This keeps `session-secret.key` in your local `instance/` directory so subsequent runs reuse it. Delete that file if you want to rotate the secret.

## Quickstart

```bash
git clone https://github.com/FeitianTech/postquantum-webauthn-platform.git
cd postquantum-webauthn-platform
docker build -t pqc-webauthn-local .
docker run --rm -p 8000:8000 --name pqc-webauthn-local pqc-webauthn-local
```

Then open `http://localhost:8000` in your browser.
